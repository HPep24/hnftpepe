Compressionism · the style

Beauty is what survives the cut.

Minimalism rose in early-1960s New York as a refusal of Abstract Expressionism: serial geometry, factory materials, and art that simply occupied space. Compressionism recasts that ethic as an emerging digital art style — treating reduction as craft, constraint as catalyst, and beauty as what survives the cut.

The material is bytes, not steel or fluorescent tubes; the site is Bitcoin, not a gallery floor. SVG vectors fit the lineage — infinite scale without quality loss, small enough that every unit earns its place. PHI 161 takes the idea to its limit: the subject is a ratio, the method is an algorithm, and the whole collection — all 161 pieces — is one file of 28,881 bytes.

Tenet 01

Reduction as craft.

Not shrinking a picture — deciding what the object can live without, until everything left is load-bearing. A PHI piece is squares, one spiral, one caption. Nothing else.

Tenet 02

Constraint as catalyst.

Bitcoin gives the whole world a few megabytes every ten minutes. Anything that wants to live there forever has to earn every byte.

Tenet 03

Beauty is what survives the cut.

Serial geometry, no ornament. What remains after the cut is the work — and only the work.

Tenet 04

Objecthood on Bitcoin.

The art is not a link to a file somewhere else. The program that draws every piece is a fragment of Bitcoin: bytes that every node keeping the full chain carries, for as long as Bitcoin runs.

The system · one rule

One rule. Sixteen lenses.

Every piece is the Euclidean algorithm drawn. Take a rectangle. Cut off the largest square that fits. Repeat on what is left, turning a quarter each time. A quarter-circle arc through every square draws the spiral.

The number of squares is not a style choice — it is the sum of the terms in the ratio's continued fraction. 3/2 is [1;2]: three squares. 34/21 is [1;1,1,1,1,1,2]: eight. φ is [1;1,1,1,…]: the sum never ends, so the cutting never stops.

Fixed on every piece

Spiral-following subdivision (left → bottom → right → top). Quarter-arc spiral at stroke 4. Keylines at 1.6. A 40-unit caption bar carrying the continued fraction, the ratio, the tier and the index — the same bar on all 161.

Variable per piece

Rung — which ratio, and so how many squares. Orientation — four rotations and a mirror. A lens for every square, drawn from sixteen. One of eight palette families. One of eight animations; the three Origins hold still.

The ladder · rarity

A Fibonacci ratio stops. φ never does.

φ is the most irrational number — its continued fraction is all ones, forever, which makes it the hardest number in existence to approximate with a fraction. Every Fibonacci ratio is a failed attempt. PHI 161 collects those failures and measures how far each one misses.

Rarity inverts deviation from φ. The crudest ratios are the rarest pieces: 1/1, 2/1 and 3/2 exist once each. φ exists once.

The mint climbs the same ladder. Pieces are minted in order — the three Origins, the thirteen Plates, then the Descents rung by rung — and the 161st mint is φ itself.

On Bitcoin · the technical route

One file. 28,881 bytes. All 161 pieces.

The collection is not 161 files. It is one program — the engine and the plan for every piece — written into the witness of a single Bitcoin transaction. There are no images in it. Each piece exists as the instruction to draw it.

Every mint creates a numbered asset, PHI.000 to PHI.160, that points back to that one file. When a piece is shown, the file reads which asset it is being shown as and draws that piece — the same squares, the same lenses, the same motion, every time.

    By hand: pull that transaction's witness from any Bitcoin node, save the HTML inside it and hash it. Open the saved file with ?asset=PHI.042 on the end of its address and it draws piece 043 — offline, with no server at all.

    No takedown

    There is no image server to unplug. The file is part of block 969,502, and every Bitcoin node that keeps full history keeps a copy.

    No silent edit

    A confirmed transaction cannot be rewritten. On ACME the issuer of an asset can point it at a new file, but only with another public transaction — so the hash above, and the check, tell anyone whether a marketplace is still showing this one.

    No expiry

    The file needs no server of its own and no domain to renew. Opened anywhere, it asks acme.pics for a 4 KB shared runtime that is also stored on Bitcoin; if that does not answer, it reads its own asset name and draws the piece anyway.

    Mint on ACME ↗ The collection file on ACME ↗
    1. Open the mint. It lives at acme.pics/dex/nft/editions/PHI. ACME is a protocol and marketplace for art stored on Bitcoin.
    2. Connect a Bitcoin wallet. ACME works with ACME Wallet, UniSat and Xverse.
    3. Press Mint Edition and sign. One piece per transaction. There is no limit per wallet.
    4. Wait for a confirmation. The piece lands in your wallet and gets its own page, like acme.pics/asset/PHI.005.
    What it costs

    16,180 sats to the artist — φ × 10,000, rounded down. On top come ACME's 888-sat protocol fee and the Bitcoin network fee for one small transaction.

    What you get

    The next piece in line, never a random one. Asset names count from zero, so they sit one below the piece number: PHI.000 is piece 001 and PHI.160 is piece 161.
